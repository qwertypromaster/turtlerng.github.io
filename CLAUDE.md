# Прокрутка (TURTLE'S RNG)

Браузерная гача/RNG-игра на ванильном JS/CSS/HTML, без сборки. Общаться по-русски, коротко и неформально.

## Файлы
- `index.html`, `style.css`, `app.js` (~1 МБ, вся логика, подключается как `type="module"`).
- `save-transfer.js` — скачивание/загрузка сохранения отдельным обычным скриптом, чтобы работало даже если `app.js` упадёт.
- `lame.min.js` (+ `lame.LICENSE.txt`) — MP3-кодер для скачивания треков из админки.
- `fonts/` — Onest и Unbounded. Остальное — картинки и звуки, которые добавил автор.
- Пути к ресурсам ОТНОСИТЕЛЬНЫЕ (`sans-theme.mp3`, не `/sans-theme.mp3`): сайт хостится на GitHub Pages в подпапке.

## Устройство app.js
- `ITEMS` — ауры и предметы; `ITEM_COLORS` — цвета; `RARITY_NAME_STYLE` — стили названий; классы редкости в `RARITY_CLASS_META`, особенные в `RARITY_CLASS_SPECIAL_IDS`.
- Темы: `applyThemeForItem(id)`. Новая система v2: `V2_SHADERS.<id>` (свои WebGL-шейдеры через `v2Bespoke`) приоритетнее `ATMOS_PRESETS` и `V2_PATTERNS`. `V2_KEEP_LEGACY` — темы, оставленные на старом коде (big_pearl, porridge_prime, matrix_*, sans, spectrum, compass).
- Шейдеры — GLSL ES 1.0: без `pow` с отрицательным основанием, без объявлений в `if` без скобок, uniform-массивы индексировать только счётчиком цикла.
- Большие 3D-сцены (пример — `V2_SHADERS.glokus_king`, первая аура класса СУПЕРСКИЙ): на Windows WebGL компилируется в HLSL, и один большой шейдер собирается минутами, замораживая страницу. Поэтому: `v2Bespoke(..., { webgl2:true, async:true })` (GLSL ES 3.00, сборка в фоне через `KHR_parallel_shader_compile`), границы циклов `i < N + ZERO` (`uniform int u_zero`), каждая функция пересечения вызывается из одного места, а сцена разбита на несколько программ через G-буфер. Время сборки проверять заранее: один шейдер не должен линковаться дольше ~3 с.
- Катсцены: у аур класса СУПЕРСКИЙ и выше при выпадении вместо трейлера `DropFX` играет фильм на 20 секунд (`CINE.<id>` + движок `Cinema` сразу после `DropFX`). Фильм — это один шейдер WebGL2, таймлайн камеры в `frame()`, титры в DOM (`setup`/`dom`, буквы из `cineLetters`), звуки по секундам (`sound`) и своя музыка (`PATCHES.cine_*`, композиторы `ST.cine_*`, 60 bpm: одна доля = одна секунда). Все фильмы собираются в фоне через 9 с после загрузки. Пока идёт фильм, темы не рисуются (`window._cinePlaying`). `opt.seek` в `DropFX.play` запускает фильм с середины (для проверки). Есть фильмы: `glokus_king` (коронация от первого лица) и `demo_super` (появление чёрной дыры).
- Музыка: движок `AMB`. Треки — `PATCHES.<id>` с полем `style`, композиторы — `ST.<style>`. Если у темы нет своего трека, играет трек погоды (`WEATHER_TRACK`), а при обычной погоде — базовые (`BASE_TRACKS`). Громкость треков выровнена примерно на −26.5 dB RMS.
- Погода: `setWeatherNow` и `startWeatherCycle`. Анимации появления — `WX_INTROS`, учитывают фильтр погоды `window._weatherFilterState`.
- Админ-панель: модуль `ADM`, код `MYCHEREPAHA`.
- Промокоды (`PROMO-…`, «Коды» в админке) несут награды, погоду, баффы и квест. Кастомный бафф — синтетическая запись в `POTIONS`; её определение лежит в `promoCustomDefs` и сохраняется вместе с игрой, как и заряды «на N прокруток» (`spinChargeEffects`). Квест из промокода — отдельная линия в `customQuests` (сохраняется), попадает в `QUEST_LINES` через `syncCustomQuestLines()`. У такого квеста может быть `expiresAt`: после него прогресс не идёт, завершить нельзя (`questLineLive`). Код с квестом имеет префикс `QUEST-` и вводится в строке над списком в меню «Квесты» (окно «Промокод» его отклоняет).
- Типы заданий квестов — `QUEST_TASK_TYPES` (event / time / state). Учёт идёт через `questEvent(type, test, amount)` и `questSet(type, valueOf)`, а таймер раз в секунду считает минуты в погоде/ночью/с темой, приход погоды, заработанные монеты и значения «накопи / достигни». У event‑заданий бывает `cond` (погода, время суток, тема, только авто‑прокрутка). Новый тип = запись в реестре + вызов `questEvent` в месте, где это событие происходит.
- В `index.html` файлы подключены с версией (`app.js?v=…`) — при каждом обновлении поднимать номер, иначе браузер берёт старый код из кеша.
- `BGClock` — таймеры в воркере, чтобы авто-прокрутка не тормозила в свёрнутой вкладке.
- `rgRun` — автоматически исправляет нечитаемый цвет текста в интерфейсе.

## Пожелания автора
- Тему «sans» визуально не трогать без прямой просьбы.
- У каши прайм не должно быть «пердёжного» трека.
- Особенные ауры нельзя удалить обычным способом.
